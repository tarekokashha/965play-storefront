# 965play storefront

**An Arabic-first gaming and electronics storefront for Kuwait, built by Tarek Okasha.**

[Live site](https://965play.com/) · [Portfolio](https://tarek-portfolio-phi.vercel.app/#brands)

## The project

I built 965play to bring gaming hardware, accessories, digital cards, and consumer technology into a single storefront. The public experience combines category navigation, product discovery, editorial buying guides, and a shopping cart.

## Experience highlights

- Arabic-first browsing across consoles, gaming accessories, PCs, and related technology.
- Buying guides that help visitors compare products before they shop.
- Product detail and cart flows for a catalog with many different item types.
- A separate identity within the portfolio's three-store 965 collection.

## Repository contents

This repository documents the storefront I built. Local files include a separate catalog-sync plugin, but its source contains commercial integration and pricing rules. Those operational details are not published here. No customer data, orders, credentials, or production configuration are included.
